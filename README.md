# Guía Práctica: Árboles Binarios de Búsqueda (BST) en C#

Proyecto académico desarrollado para la Universidad Estatal Amazónica (UEA), enfocado en la implementación, 
operaciones y representación gráfica de un **Árbol Binario de Búsqueda (BST)** utilizando C# y Windows Forms 
en .NET.

##  Características
* Inserción recursiva de nodos (Clave y Valor).
* Recorrido y ordenamiento automático de los elementos.
* Interfaz gráfica de escritorio mediante Windows Forms (`TreeView`).

##  Requisitos y Ejecución
1. Tener instalado [.NET SDK](https://dotnet.microsoft.com/) (versión 10.0 o superior recomendada).
2. Clonar el repositorio o abrir la carpeta en **Visual Studio Code**.
3. Ejecutar el siguiente comando en la terminal integrada:
   ```bash
   dotnet run
